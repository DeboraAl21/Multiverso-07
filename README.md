# Nerd Universe Database

Projeto desenvolvido em MongoDB para higienização, normalização e consulta de dados de personagens do universo nerd.

## Coleções

* characters
* universes
* species
* equipment
* movies

## Tecnologias

* MongoDB
* MongoDB Compass
* JavaScript

## Funcionalidades

* Limpeza e padronização dos dados.
* Relacionamento entre coleções por IDs.
* Consultas utilizando
